# Deck structure

One slide per project keeps the deck short; the detail page holds every change.

| Slide | Content |
|---|---|
| cover | Title, dates, one coloured square per project with a legend for the groups |
| goal | The runs' goal as a headline, its parts as three cards, one line on how the rounds relate |
| overview | Four big numbers: projects, changes kept, fixes after the runs, goals met; one line on what is committed or pushed |
| status | Projects as chips in group columns: goal met in the run, fixed after the run, needs a decision |
| one per project | See `project.html` |
| untested | Table: not tested, where it matters, what was done instead |
| decisions | One card per decision with Done or Waiting |
| more | Link to the detail page; say it must be shared too |

Project slide, left column: group chip, project name and what it is, a "Goal:" line, a
headline about the user's gain, three wins (after-run wins start with a bold "After the
run:"), and a "Still open" or "Needs a decision" box. Right column: a before/after screenshot
pair or one screenshot, each with a label. Footer: a link "All N changes: what, why and how"
to `<detail page>#p-<repo>`. Speaker notes: every change per round in one paragraph.

Palette (light): background #F5F6F2, ink #16202A, muted #4B5763, accent #B4501F, goal met
#DDE9F4 / #1F5486, fixed #DCEFEC / #1B5E57, decision #FBE3D3 / #8F3E12. Dark slides use
#16202A with cards #223040. Fonts: Rubik for headings, Public Sans for text.
